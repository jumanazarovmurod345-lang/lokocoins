# LokoCoins — Премиальный игровой Telegram Mini App

Игровой Telegram Mini App портал нового поколения:
- **Flask** веб-сервер с API для мини-приложения (`web/index.html`).
- **python-telegram-bot**, запускающий бота, генерирующий реферальные ссылки, обрабатывающий команды и уведомления администратора.
- **SQLite (data.db)** — база данных для хранения профилей, балансов, инвентаря, лидербордов и заявок на пополнение.

---

## 🎨 Обновленный дизайн и цветовая схема
- **Цветовая палитра:** Тёмный премиальный фон с яркими золотыми, оранжевыми, огненно-красными и белыми акцентами.
- **Нижняя навигация:** 4 вкладки — **Игры**, **Кейсы**, **Профиль**, **Пополнение**.
- **Плавные анимации:** Вращение колеса апгрейда с замедлением, анимация полёта ракеты и траектории, рулетка открытия кейсов, парящие частицы тапов.

---

## 🎮 Игры

### 1. Апгрейд (Колесо удачи)
- Игрок вводит ставку (⭐ Звёзды или 🪙 LokoCoins).
- Выбор множителя (1.5x, 2.0x, 3.0x, 5.0x, 10x, 20x).
- Крутящееся колесо с яркой фиолетовой выигрышной зоной и стрелкой-указателем.
- Выигрыш начисляется при остановке стрелки на фиолетовом секторе.

### 2. Ракета (Crash)
- Ввод ставки и кнопка **«Взлететь 🚀»**.
- Ракета плавно взлетает с графиком траектории и растущим в реальном времени множителем (1.00x ... 100.00x).
- Кнопка **«Забрать»** для фиксации выигрыша.
- **После вывода ракета не останавливается**, а продолжает полёт, показывая максимальный множитель до момента взрыва.

### 3. Loko Тапалка (вместо Дровосека)
- Игра на скорость нажатий по 3D-монете без ставок.
- Эффекты нажатий, виброотклик и вылетающие очки `+1`.
- **Таблица лидеров** с реальными наградами:
  - 🥇 **1 место — 50 звёзд**
  - 🥈 **2 место — 25 звёзд**
  - 🥉 **3 место — 1000 LokoCoins**

## 📦 Кейсы (4 вида)
1. **Пляжный кейс (15 ⭐)** — высокий шанс на Пляжного Мишку 🧸 + LokoCoins.
2. **Подарочный кейс (20 ⭐)** — официальные Telegram-подарки от 15⭐ + монеты.
3. **Редкий кейс (25 ⭐)** — Telegram-подарки + **шанс 0.5% на эксклюзивный NFT-подарок**!
4. **Элитный кейс (50 ⭐)** — премиальные Telegram-подарки + **шанс 1.0% на NFT**!

Все выпавшие подарки и NFT сохраняются в **Инвентарь** игрока.

## 👤 Профиль и система статусов
- **Статусы игроков:**
  - **Гость** — начальный статус.
  - **Местный** — от 50 ⭐ или 100 000 сум (бонус +500 🪙).
  - **Крутой** — от 150 ⭐ или 150 000 сум (бонус +25 ⭐ на баланс).
  - **Элита** — от 500 ⭐ или 250 000 сум (бонус +250 ⭐ и +1000 🪙).
- **Инвентарь:** Карточки всех полученных подарков и NFT.
- **Реферальная ссылка:** Персональная ссылка для каждого пользователя со счетчиком приглашенных.
- **Промокоды:** Поле активации промокодов (`LOKO10`, `BONUS` и др.).

## 🚀 Запуск и деплой

### 1. Установка зависимостей:
```bash
pip install -r requirements.txt
```

### 2. Настройка `.env`:
```ini
BOT_TOKEN=токен_от_BotFather
OWNER_ID=ваш_telegram_id
BOT_USERNAME=LokoCoins_Bot
WEBAPP_URL=https://ваш-домен-на-render.com
PORT=10000
```

### 3. Запуск:
```bash
python bot.py
```

Готов к деплою на **Render.com** по файлу `Procfile`.
