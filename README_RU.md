# LokoCoins — Премиальный игровой Telegram Mini App v2.1

Игровой Telegram Mini App портал нового поколения:
- **Flask** веб-сервер с API для мини-приложения (`web/index.html`).
- **python-telegram-bot**, запускающий бота, генерирующий реферальные ссылки, обрабатывающий команды и уведомления администратора.
- **SQLite (data.db)** — база данных для хранения профилей, балансов, инвентаря, лидербордов и заявок на пополнение.

---

## 🎨 Дизайн и навигация
- **Цветовая палитра:** Тёмный премиальный фон с оранжево-чёрным неоном (`#08080b`, яркий оранжевый `#ff6600`, золотой `#ffc400`, красный `#ff2222`).
- **Главный экран раздела «Игры»:** Каталог стильных неоновых кнопок-карточек:
  - ⬆️ **Апгрейд** — умножение баланса со стрелкой удачи
  - 🚀 **Ракетка** — игра Crash со свободным полётом
  - 👆 **Тапалка** — кликер без ставок с призовым фондом в топе
  - 🎡 **Колесо (Рулетка)** — колесо фортуны с множителями до 20x
- **Нижняя навигация (4 вкладки):**
  1. **Игры**
  2. **Кейсы**
  3. **Профиль**
  4. **Пополнение**

## 🎮 Игры

### 1. Апгрейд (Стрелка вверх)
- Выбор ставки (⭐ или 🪙) и множителя.
- Фиолетовая выигрышная зона на колесе, вращение и остановка стрелки.

### 2. Ракетка (Crash)
- Ввод ставки, взлёт ракеты и динамический график траектории.
- Кнопка «Забрать» фиксирует выигрыш, но **ракета продолжает полёт дальше**, наглядно показывая максимальный множитель до взрыва.

### 3. Тапалка (👆 Loko Tap)
- Тапы по 3D-монете с виброоткликом и парящими числами.
- **Таблица лидеров** с реальными наградами:
  - 🥇 **1 место — 50 ⭐**
  - 🥈 **2 место — 25 ⭐**
  - 🥉 **3 место — 1000 🪙**

### 4. Колесо (Рулетка)
- Плавная физика вращения с лоадером перед стартом и остановкой.
- Множители: 1.5x (60%), 2.0x (45%), 3.0x (30%), 5.0x (18%), 10x (9%), 20x (4.5%).

## 🎁 Вывод подарков (Инвентарь)
- В инвентаре у каждого предмета есть кнопка **«Вывести подарок»**.
- **Условия вывода:**
  1. Пригласить минимум **2 друзей** по личной реферальной ссылке.
  2. Наличие **25 ⭐** на балансе (комиссия за вывод).
- При выводе с баланса списывается 25 звёзд комиссии, создается заявка, и администратор получает уведомление в Telegram для отправки подарка.
